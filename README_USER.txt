==========================================================
  Qwen i2v Studio  —  이미지를 영상으로 자동 변환
==========================================================

이미지 폴더를 넣으면 Qwen AI로 각 이미지를 영상으로 만들어
자동으로 저장해 주는 프로그램입니다. 여러 Qwen 계정을 동시에
돌려서 더 많이/빠르게 뽑을 수 있습니다.


■ 준비물
  - 윈도우 10 / 11
  - 구글 크롬(Chrome) 설치
  - Qwen 계정 (https://chat.qwen.ai 에서 무료 가입)
  - 인터넷 연결
  ※ 파이썬 설치 필요 없음 — 프로그램 안에 포함되어 있습니다.


■ 처음 한 번
  1. 받은 zip 파일을 "압축 풀기" 합니다.
     (폴더 통째로 풀어야 합니다. python 폴더가 같이 있어야 함)
  2. 폴더 안의  실행하기.bat  를 더블클릭합니다.
  3. 처음에는 자동 준비에 2~3분 걸립니다 (한 번만).
     검은 창에 설치 진행 글이 지나갑니다 — 닫지 말고 기다리세요.
  4. 끝나면 인터넷 브라우저에서 화면이 자동으로 열립니다.


■ 사용법
  [1단계] 계정 만들기
    - "계정 개수"에 숫자를 넣고 (예: 3)
      [+ N개 추가 & Chrome 열기] 클릭
    - 크롬 창이 그 개수만큼 자동으로 뜹니다.
    - 각 크롬 창에서 서로 다른 Qwen 계정으로 로그인하세요.
      (처음 한 번만. 자동인증/캡차는 직접 통과)
    - 로그인 다 했으면 [✓ 전체 로그인 확인] 클릭
      → 카드가 "로그인 완료"로 바뀝니다.

  [2단계] 이미지 넣기
    - "이미지 폴더"에 영상으로 만들 이미지가 든 폴더 경로를 넣고
      [📂 불러오기] 클릭
    - 이미지 썸네일이 칸칸이 뜹니다.
    - 만들 컷을 클릭해서 고르세요. (아무것도 안 고르면 전체 생성)
    - 프롬프트 파일은 선택 사항 — 비워두면 기본 영상화 효과로 만듭니다.

  [3단계] 실행
    - [▶ 배치 시작] 클릭
    - 진행 상황이 실시간 로그에 표시됩니다.
    - 끝나면 [📂 다운로드 폴더 열기]에서 결과 영상(mp4) 확인.


■ 이미지 파일 이름 규칙
    scene_01.jpg, scene_02.png, scene_03.jpg ...
    (scene_ 뒤에 두 자리 숫자. 이 숫자 순서로 처리됩니다)


■ 한도 안내
  - Qwen 무료 한도: 한 계정당 3시간에 약 4~5개 영상.
  - 더 많이 뽑으려면 계정을 여러 개 만들어 동시에 돌리세요.
  - 한도에 걸린 계정은 카드가 "한도 도달"로 바뀌고 그 계정만 멈춥니다.
    나머지 계정은 계속 돌아갑니다.


■ 자주 묻는 질문
  Q. 검은 창을 닫아도 되나요?
     → 안 됩니다. 그 창이 프로그램 본체입니다. 끄면 종료됩니다.

  Q. 다시 켤 때도 2~3분 걸리나요?
     → 아니요. 처음 한 번만. 이후에는 바로 열립니다.

  Q. 로그인은 매번 해야 하나요?
     → 아니요. 한 번 로그인하면 그 PC에 저장됩니다.

  Q. 백신이 경고해요.
     → 파이썬 실행 파일이라 드물게 오탐이 납니다. 신뢰/허용 하세요.

  Q. 화면이 안 열려요.
     → 인터넷 브라우저 주소창에 직접 입력:  http://localhost:8765


■ 주의
  - 본인 Qwen 계정으로만 사용하세요. 계정 정보는 본인 PC에만 남습니다.
  - Qwen 약관을 지켜 개인 용도로만 사용하세요.
